# Agent system instruction doc
## Project Spec
This is a group project for CSCI345 Object Oriented Design. 
## Code Practices
- The primary language used is Typescript
- All ai-generated files should begin with a comment similar to:
"""
{Filename}
Description: {briefly describe classes, use}
Date: {}
Generated by: {AI model name}
Reviewed by: __________
"""
- All functions and modules/classes should have docstrings documenting usage and arguments
